Exercício 1 — Verificação de Número Positivo ou Negativo em Java
Desenvolvimento de um programa em Java que solicita ao usuário a entrada de um número inteiro e verifica se ele é positivo, negativo ou igual a zero, utilizando estruturas condicionais (if, else if e else).
Conceitos praticados:
- Entrada de dados com Scanner.
- Estruturas condicionais em Java.
- Operadores relacionais.
- Lógica de programação.
Objetivo: praticar os fundamentos da linguagem Java e desenvolver o raciocínio lógico por meio de condições.
